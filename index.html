About The Project

Customer churn refers to customers who stop using a company's products or services. This project analyzes customer information to understand the factors that influence churn.


The project uses Python, Pandas, NumPy, Matplotlib, Seaborn and Machine Learning techniques for data cleaning, exploratory data analysis, visualization and prediction.
